# בנג׳ו ברחוב — V2 (4 שלבים) — ראה V2_NOTES.md

## איך פותחים
- הכי פשוט: לפתוח את `index.html` בדפדפן (Chrome / Safari / Firefox) — עובד גם ב-file://.
- לטלפון / מניעת בעיות טעינה: `cd prototype && python3 -m http.server 8000` ואז `http://<IP>:8000` בטלפון באותה רשת.
- טלפון: לסובב לרוחב. אין צורך ב-npm/build.

## שליטה
| פעולה | מקלדת | טאץ׳ |
|---|---|---|
| תנועה (ימין/שמאל + עומק למעלה/למטה) | חיצים | ג׳ויסטיק משמאל |
| אגרוף קל (קומבו 3 מכות) | Z | קל (כחול) |
| אגרוף כבד (מפיל) | X | כבד (אדום) |
| הרמה/תפיסה → זריקה | C (לחיצה ראשונה מרימה/תופסת, שנייה זורקת) | זריקה (כתום) |
| נגיחה (החזק+שחרר) | Shift או חץ כפול | נגיחה |

| התחל / שוב | Enter / רווח או כפתור | כפתור |

תפיסה: אפשר לתפוס בריון שנמצא בהלם/פצוע (לא את הגדול). זריקתו מפילה בריונים אחרים בדרך. חפצים: פח, ארגז, בקבוק.

## מהלך
3 גלים של בריונים (רגיל / מהיר / גדול). המצלמה ננעלת עד שהגל מנוקה, אז "קדימה ←". ניצחון = ניקוי 3 הגלים (בונוס זמן + חיים). הפסד = חיים 0. ניקוד על נוקאאוט, מוכפל לפי קומבו.

## תחושת משקל (כיוונון בראש הסקריפט: `P`, `ATK`, `COMBO_WINDOW`)
- **תאוצה/חיכוך**: accel 1700, decel 2300 px/s² → בנג׳ו נכנס למהירות ועוצר עם החלקה קצרה, לא "גלישה פלסטית". שינוי כיוון מקבל boost (×1.6) כדי להרגיש נטיעה של הרגל.
- **התקפות** בשלבים: startup → active → recover. בזמן האגרוף יש lunge קדימה (משקל גוף), ובפגיעה התנועה נבלמת.
- **Hit-stop**: הקפאת עולם 50–120 מ״ש לפי עוצמת המכה + רעידת מצלמה + חלקיקים.
- **Knockback** מחולק במסה של האויב (הגדול זז פחות); מכה כבדה/שלישית בקומבו מעיפה לאוויר עם גרביטציה וקפיצה ברצפה.
- **התנגשות גופים**: דחיפה הדדית לפי מסה — אי אפשר לעבור דרך בריונים.
- פיזיקה ב-fixed step של 120Hz — עקבי בכל מכשיר.
- אויבים מסמנים "!" לפני מכה (חלון התחמקות), מקסימום 2 תוקפים במקביל.
